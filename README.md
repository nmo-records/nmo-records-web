# NMO Records — sitio web

Sitio estático de NMO Records. Está hecho con HTML, CSS y JavaScript, sin dependencias ni proceso de compilación.

## Páginas

- `index.html`: portada de NMO Records.
- `asesoria.html`: información sobre la asesoría y el acompañamiento de lanzamientos.
- `artistas.html`: proyectos acompañados.
- `nikoni.html`: ficha de NIKONI, créditos y reproductor de “Cuando me miras”.

Las imágenes, el logo y el audio están en `assets/`. Conserva esa carpeta junto a los archivos HTML.

## Ver el sitio en tu computadora

Abre `index.html` en un navegador. No requiere instalar programas.

## Publicar con GitHub y Vercel

1. Crea un repositorio en GitHub y sube el contenido de esta carpeta, incluyendo `assets/`.
2. En Vercel, importa ese repositorio. El sitio usa la raíz del proyecto y no requiere comando de compilación.
3. Prueba la dirección `vercel.app` antes de conectar un dominio propio.

Vercel indica que su plan Hobby es para uso personal y no comercial. Si el sitio se usa para promover un servicio o actividad con fines comerciales, revisa sus condiciones y el plan apropiado antes de publicarlo.

El reproductor usa `assets/cuando-me-miras-demo_nmoformat.wav` (aprox. 5.6 MB), así que cabe dentro del límite de carga desde la interfaz web de GitHub. El audio servido desde la página será accesible para quienes visiten el sitio.

## Contacto

Los enlaces de contacto actuales son WhatsApp e Instagram. Si cambias una dirección, actualízala en las cuatro páginas HTML.
